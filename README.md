# Rename the Planet

One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters.

## Entry

> Jupiter, renamed 'The Grudge,' because it has nursed one storm bigger than Earth for three hundred years and refuses to let it go.

## How it works

`main.py` writes the entry line to `/output/entry.txt` and prints it to stdout. No network, no secrets, no dependencies — just the line.
